# Ecommerce Sales Analytics Dashboard

A web-based e-commerce sales analytics dashboard developed using Python, Flask, and Apache PySpark to analyze sales data, apply filters, and generate meaningful business insights.

## Features

* Interactive sales analytics dashboard
* Sales data processing using PySpark
* Data filtering and analysis
* Key sales performance metrics
* User-friendly web interface
* Data analysis using Pandas

## Tech Stack

* **Programming Language:** Python
* **Backend:** Flask
* **Data Processing:** Apache PySpark, Pandas
* **Frontend:** HTML, CSS, JavaScript
* **Development Environment:** Visual Studio Code

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Ecommerce-Sales-Analytics.git
```

### 2. Navigate to the project directory

```bash
cd Ecommerce-Sales-Analytics
```

### 3. Install dependencies

```bash
pip install flask pyspark pandas
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in browser

```text
http://127.0.0.1:5000
```
